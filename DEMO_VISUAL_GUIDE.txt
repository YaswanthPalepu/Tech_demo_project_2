│ UNDERSTANDING THE PARAMETERS                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

--target PATH
    └─> Points to YOUR SOURCE CODE
    └─> Examples: ./target, ./src, ./app, ./myproject
    └─> This is what you're TESTING

--tests-dir PATH (optional, default: tests/generated)
    └─> Points to GENERATED TESTS
    └─> This is WHERE the tests are

--max-iterations N (optional, default: 3)
    └─> How many times to retry healing

--full-source (optional flag)
    └─> Use complete source files instead of AST snippets
    └─> Slower but more accurate
